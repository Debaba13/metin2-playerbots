PLAYERBOTS · GÜNCELLEMELER

⬆ Tieru Güncelleyicisi

Bu düğme Tieru'nun ana daldan en yeni kodunu indirir, imajları hazırlar ve karakter ile veritabanı birimlerini silmeden standart bir Docker dağıtımı çalıştırır.

VPS'te güncelleyiciyi çalıştırma talimatları

Bu düğme, Tieru'nun resmi updater servisi bir kez kurulduktan sonra çalışır. Panel şifre korumasını açın, VPS'e SSH ile bağlanın ve şunu çalıştırın:

STACK=/opt/metin2/stack
PANEL=/opt/seban-panel
docker volume ls --format '{{.Name}}' | grep 'update-spool$'
printf '\nPLAYERBOTS_UPDATE_SPOOL_VOLUME=BULUNAN_VOLUME_ADI\n' >> "$PANEL/seban-panel.env"
cd "$PANEL" && docker compose --env-file seban-panel.env up -d --build seban-panel
cd "$STACK" && docker compose --profile update up -d updater
docker compose exec updater m2-updater selftest

Test everything it needs is here mesajıyla bittiğinde bu sayfayı yenileyin. Test r40250 sunucu paketinin eksik olduğunu bildirirse, panel paketine eklenen UPDATER_VPS.md dosyasına göre kendi yasal arşivinizi hazırlayın.
